# AutoFlow Studio Chrome 扩展

这是一个按站点配置页面自动化流程的 Chrome 扩展，aTrust 是内置的默认规则。

## 功能

- 在 Chrome Side Panel 中管理多个网站规则。
- 侧栏会跟随当前激活标签页、页面跳转和窗口切换更新当前页面信息。
- 当前页面是 HTTP/HTTPS 时，面板底部会显示“快速新建”，自动使用当前标题和 URL 生成规则草稿；无论当前网站是否已授权或已有匹配规则，都可以继续创建新的页面规则。
- “新建”直接进入空白规则编辑页，不会读取当前标签页 URL；“解析 URL”只解析输入框中粘贴的地址。
- 同一域名下可建立多个页面规则，按路径前缀和 Hash 前缀匹配；面板按域名分组展示。
- 域名分组默认折叠，点击域名行可展开；新建规则或点击某条规则时自动展开对应域名。
- 面板打开时默认进入规则总览，不自动选中第一条规则；点击新建或已有规则后进入独立的规则编辑模式，保存成功返回总览。
- 编辑模式返回总览时会提示未保存修改；新建草稿若未保存，返回时会丢弃该草稿。
- 如果多个规则同时匹配同一页面，优先执行路径和 Hash 条件更具体的那一条；建议页面规则尽量使用不重叠的匹配范围。
- 在真实页面上点选元素，自动记录可读的元素特征和 CSS 选择器。
- 按顺序执行填充、勾选、选择、点击、等待元素出现、等待指定毫秒和刷新页面；刷新页面是终止性步骤。
- 点击“添加步骤”只创建步骤，不会立即进入拾取模式；先选择执行动作，需要 DOM 目标时再点击该步骤的“选择元素”。
- 二期分支增加条件触发：元素出现/变为可见、用户点击元素；同一页面允许多条规则进入统一执行队列，并带有防重复和冷却状态。
- 支持先点击“密码登录”再等待账号密码弹窗出现的流程。
- 有一个总开关和每个站点的独立开关；总开关关闭时暂停自动执行，规则编辑页的“保存并测试一次”仍可手动验证当前流程。
- 每个域名分组右侧有批量开关，可一次启用或停用该域名下的全部页面规则；部分规则启用时显示中间状态。
- 步骤详情支持折叠，站点列表和步骤列表有最大高度，规则多时在面板内滚动。
- 当前页面“快速新建”会自动带入当前页面的来源、路径和 Hash；查询参数不自动带入，避免把临时参数写进匹配规则。
- 也可以在“快速新建”中直接粘贴完整 URL，解析后再配置该页面的步骤。
- 每个域名分组提供下载图标，用于打开规则选择导出；分享文件默认隐藏填充值和密码。
- “站点规则”标题右侧的导出图标用于导出完整备份，包含密码并需要确认；导入图标可导入规则分享或完整备份。浏览器访问权限不会随文件导入，需要首次使用时重新授权。
- 域名分组的下载图标会打开导出弹窗，可在“本地文件”和“剪贴板”之间选择，并勾选需要导出的页面规则。
- 导入剪贴板内容时直接粘贴到文本框即可，不需要额外的读取按钮。
- 规则分享导入按网站来源、路径前缀和 Hash 前缀识别重复规则；重复项会合并并保留本地已有值，有值冲突时以本地为准。完整备份仍会覆盖全部规则。
- 动态渲染页面会等待目标元素出现，输入框会触发 `input` 和 `change` 事件。

完整规则由 Worker/Panel 保存到 chrome.storage.local；Content Runtime 默认只能拿到当前页面的脱敏规则 Snapshot，执行填充或选择步骤时，Worker 才按当前 runId、页面 document 和 revision 下发单个值。Chrome 扩展本地存储不是密码管理器级别的加密保险箱，密码最终仍会进入目标网页 DOM，请只在个人设备上使用。

运行失败时可在 Panel 当前页面区域打开“查看运行日志”。日志仅保留当前扩展会话的脱敏事件；诊断复制会去掉 URL 的 query/hash，不包含填充值、Cookie、Token 或剪贴板原文。

扩展默认只包含 aTrust 的网站权限。新增其他网站时，保存规则会按网站单独请求访问权限，不默认申请所有网站权限。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`atrust-auto-login`。
5. 将扩展固定到工具栏，点击图标打开 Side Panel。
6. 选择现有规则，或点击“新建”。在目标页面添加步骤并按顺序选择元素。
7. 填写值，密码字段勾选“密码字段”，打开站点规则开关后保存。

扩展代码本身不包含任何账号或密码。元素拾取模式可按 `Esc` 取消。
