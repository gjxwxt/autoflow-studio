隐私政策

AutoFlow Studio 是一个本地优先的 Chrome 扩展，用于保存并执行用户自行配置的网页自动化规则。

生效日期：2026 年 9 月 10 日 适用范围：AutoFlow Studio Chrome 扩展
✓

AutoFlow Studio 不设开发者云端账户、分析服务或同步服务。规则和凭据默认只保存在你的 Chrome 配置中，不会上传到我们的服务器。

1. 我们处理哪些数据

为了完成你主动配置的自动化操作，扩展可能在本地处理以下信息：

  • 你创建的站点规则，包括网站来源、路径或 Hash 匹配条件、步骤名称、元素选择器和操作参数。
  • 你主动填写到规则中的用户名、密码及其他表单值。此类值属于敏感信息。
  • 当前页面的标题、URL 和用于匹配规则的页面元素特征。
  • 当前扩展会话中的脱敏运行诊断，例如规则、步骤、动作、结果和错误代码。

2. 我们如何使用这些数据

这些信息仅用于：

  • 在 Chrome 侧边栏中展示和编辑你的规则。
  • 在匹配的网页中执行你配置的填充、勾选、选择、点击、等待或刷新操作。
  • 在你主动请求时导入、导出、分享规则或查看运行诊断。

扩展不会基于这些信息建立用户画像，也不会将其用于广告、推荐或与自动化功能无关的用途。

3. 数据存储与保留

规则配置和敏感值保存在 Chrome 的本地扩展存储中；运行时诊断保存在当前扩展会话的临时存储中。我们没有可访问这些本地数据的开发者后台。

数据会保留到你删除规则、清除扩展数据或卸载扩展为止。你可以随时在扩展界面删除规则，或通过 Chrome 的扩展管理页面清除扩展数据。

4. 导入、导出与分享

导入和导出均由你主动发起：

  • 规则分享默认不包含填充值和密码。
  • 完整备份可能包含密码和其他敏感值，扩展会在导出前提示确认。
  • 导出到文件或剪贴板后，数据会由 Chrome 和你的操作系统按相应机制处理；请只在你信任的位置保存或粘贴。

5. 浏览器权限

扩展使用 Chrome 权限来完成本地功能：

  • storage：保存本地规则、开关和会话诊断。
  • sidePanel：提供规则管理界面。
  • activeTab、tabs：读取当前页面信息，并把规则执行到匹配的标签页。
  • scripting：在你配置并授权的网站上运行页面规则。

除内置的 aTrust 页面外，其他网站的访问权限会在你保存对应规则时按站点请求，不默认开启所有网站。

6. 第三方网站与安全边界

扩展会按照你的规则与目标网站页面交互。目标网站如何处理你提交的表单数据，受该网站自己的隐私政策约束，AutoFlow Studio 无法控制。

Chrome 本地扩展存储不是经过加密的密码管理器保险箱；密码在执行填充时也会进入目标页面的 DOM。请仅在你信任的设备、浏览器配置和网站上使用，并避免把完整备份放在不安全的位置。

7. 政策变更与联系我们

如果数据处理方式发生变化，我们会更新本页面的生效日期和内容。你可以通过 GitHub Issues 提交隐私问题、漏洞报告或其他反馈。

本政策仅说明 AutoFlow Studio 扩展的数据处理方式，不构成法律、财务或安全建议。
